Phishing Email Checker

Analyze email text, headers, authentication results, sender domains, and links

Paste an email and click Analyze Email.

Including full headers allows stronger checks such as SPF, DKIM, DMARC and Reply-To mismatches.

Heuristic analysis: this checker looks for suspicious characteristics; it cannot prove an email is safe or malicious. If the message contains a link, use the separate URL Checker for a live reputation lookup.

URL Checker — Is it Safe?

Inspect a suspicious link without opening the destination

Paste a suspicious link above. The checker analyzes the URL text and, when configured, checks Google Web Risk.

A clean result is not a guarantee of safety. Threat intelligence can have false positives and false negatives, and brand-new malicious sites may not be listed yet. This tool never intentionally opens the submitted destination URL.
